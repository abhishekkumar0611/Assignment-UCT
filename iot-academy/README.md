# The IoT Academy – Data Science, Machine Learning & AI Landing Page

A responsive landing page recreated from the provided Figma design using **React.js, Vite, and Tailwind CSS**.

The project focuses on building a modern education/course landing page with responsive sections for desktop and mobile devices.

---

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript (ES6+)
- Lucide React
- HTML5
- CSS3

---

## Features

- Fully responsive design
- Desktop and mobile layouts
- Navigation header
- Hero section
- Program USPs
- Program value section
- Course curriculum
- Live industry projects
- Who should join the program
- Faculty section
- Career services
- Course fee structure
- Scholarship information
- Responsive cards and grids
- CTA buttons
- Hover effects
- Modern gradient sections
- Reusable React components
